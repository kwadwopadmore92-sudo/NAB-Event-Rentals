HOW TO ADD YOUR OWN PHOTOS
===========================

Each rental category on the Home and Catalog pages has a photo slot.
Right now it shows a soft color placeholder. To show a real photo instead,
just drop an image into this "images" folder using the exact filename
below (any of these formats work: .jpg, .jpeg, .png — if you use a
different extension, update the "src" in the HTML to match).

  images/florals.jpg           -> Florals
  images/table-linens.jpg      -> Table Linens
  images/glassware.jpg         -> Glassware
  images/charger-plates.jpg    -> Charger Plates
  images/kids-chairs.jpg       -> Kids' Chairs
  images/artificial-grass.jpg  -> Artificial Grass
  images/candle-stands.jpg     -> Candle Stands
  images/tables.jpg            -> Tables
  images/chafing-dishes.jpg    -> Chafing Dishes & Food Pans

Tips:
- Landscape photos (wider than tall), around 800x600px or larger, work best.
- Keep file sizes under ~500KB each so pages load quickly.
- As soon as a matching file is added, it will automatically appear on
  both the Home page and the Catalog page — no code changes needed.
- If a photo is missing, the colored placeholder simply stays in place,
  so the site never shows a broken image icon.
